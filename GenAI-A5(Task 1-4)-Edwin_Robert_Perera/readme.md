## Requirements

- Python 3 is required.
- No additional packages are needed; the project uses only standard library modules.

## Directory structure

- `main.py` - project entry point. Runs sample math, string, and shop functions.
- `math_utils.py` - contains math helper functions like addition, subtraction, and square.
- `string_utils.py` - contains text helper functions like capitalization, reversing text, and word count.
- `shop_package/` - package folder for shop-related utilities.
  - `shop_package/__init__.py` - makes `shop_package` a Python package.
  - `shop_package/discount.py` - contains discount calculation functions.
  - `shop_package/billing.py` - contains billing functions such as total calculation.

## Files used by the entry point

- `main.py`
- `math_utils.py`
- `string_utils.py`
- `shop_package/discount.py`
- `shop_package/billing.py`
