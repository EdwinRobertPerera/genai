## Program Contents

### Task 1 – Basic Functions

- Calculates the final price after applying a discount.
- Demonstrates function parameters with a default value.
- Uses exception handling (`try` / `except`) to handle invalid input types.

---

### Task 2 – Recursive Function

- Calculates the factorial of a number using recursion.
- Handles invalid negative inputs.

---

### Task 3 – Lambda Function

- Uses a lambda function to calculate GST (18%) on a given price.

---

### Task 4 – map()

- Applies GST to every element in a list of product prices using `map()`.

---

### Task 5 – filter()

- Filters product prices into:
  - Prices greater than 500
  - Prices less than or equal to 500

---

### Task 6 – Combined Utility

- Uses `map()` to process prices.
- Uses `filter()` to retrieve prices above a specified value.

---

### Task 7 – Menu Driven Program

Provides a simple menu allowing the user to:

1. Add a Price
2. Show Average Price
3. Show Highest Price
4. Quit the Program

The menu continues until the user chooses the Quit option.
