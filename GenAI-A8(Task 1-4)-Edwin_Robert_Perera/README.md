# Streamlit Practice Apps

This project contains four beginner-friendly Streamlit applications.

## Requirements

Install Streamlit:

```bash
pip install streamlit
```

## Applications

### 1. Basic Streamlit App

File: `app_basic.py`

- Displays a welcome title.
- Accepts a user's name.
- Shows a greeting when **Greet Me** is clicked.

Run it with:

```bash
streamlit run app_basic.py
```

### 2. Price Calculator

File: `app_discount.py`

- Takes a product price.
- Takes a discount percentage from 0 to 500.
- Calculates and displays the final price.
- Shows a before-and-after comparison table.

Run it with:

```bash
streamlit run app_discount.py
```

### 3. Product Form

File: `app_product_form.py`

- Uses the sidebar to collect product name, category, and price.
- Displays a success message and product details after submission.

Run it with:

```bash
streamlit run app_product_form.py
```

### 4. Mini Sales Dashboard

File: `app_dashboard.py`

- Lets the user select a month.
- Displays sales for the selected month.
- Shows monthly sales in a bar chart.

Run it with:

```bash
streamlit run app_dashboard.py
```
