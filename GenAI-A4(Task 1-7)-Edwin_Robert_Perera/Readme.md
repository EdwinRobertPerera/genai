The program consists of 7 tasks covering writing, reading, appending, summarizing data, user input, error handling, and generating a discount report.

---

## Requirements

- Python 3.x

No external libraries are required.

---

## Files Created

When the program runs, it automatically creates the following files:

- `sales_data.txt`
- `products.txt`
- `discount_report.txt`

---

## How to Run

1. Make sure Python 3 is installed.

2. Save the program as:

```
a4.py
```

3. Open a terminal or command prompt.

4. Navigate to the folder containing the program.

Example:

```bash
cd path/to/your/folder
```

5. Run the program.

On Windows:

```bash
python a4.py
```

or

```bash
py a4.py
```

On Linux/macOS:

```bash
python3 a4.py
```
